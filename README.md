# Tolk

Переводит русский ↔ английский прямо там, где печатаешь. Windows 11.

- **Alt+Q** — перевести только что набранное слово (ещё раз — фразу) или выделенный текст и заменить на месте.
- **Ctrl+Z** сразу после перевода — вернуть как было.
- **Alt+1…5** — выбрать другой вариант перевода слова.
- **Клик по значку в трее** — то же, что Alt+Q; если переводить нечего — окно-переводчик.
- **Alt+Shift+Q** — перевести текст с области экрана.

Перевод — онлайн (без ключей) с офлайн-моделью про запас. Набранный текст не пишется на диск и не уходит в сеть, пока
ты сам не попросишь перевод.
